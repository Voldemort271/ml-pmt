# Anonymous Artifact — AST 2027 Short Paper

This artifact accompanies the submission **“Predicting Mutant Behaviour for Fault Localization: When It Works and When It Does Not.”** It contains the benchmark corpus, the analysis code, the per-bug results reported in the paper, and the pipeline figure.

The large BugsInPy checkouts and per-project virtual environments are intentionally omitted. They are regenerated by `scripts/setup_benchmark.py`.

## Contents

- `data/pairs.csv` — 236,013 test–mutant training/prediction rows.
- `data/fault_labels.csv` — 311 known fault lines.
- `data/diffuse/` — the small synthetic diffuse-coverage corpus used for the controlled check.
- `artifacts/revision_v7/` — per-bug ranks, tie-aware metrics, expressibility funnel, prediction diagnostics, calibration results, and cost counts.
- `artifacts/fusion_cache.pkl` — cached SBFL spectra used by the tie-aware analysis. Absolute build paths were sanitized to repository-relative paths.
- `ml_pmt/`, `mutation_engine/`, `execution/`, `features/` — the ML-PMT implementation.
- `scripts/revision_analysis.py` — reproduces the revision analyses and writes `artifacts/revision_v7/`.
- `scripts/make_fig2_prediction.py` — optional ROC figure generator.
- `tests/` — 26 tests for the model, scripts, mutation engine, and leakage checks.
- `docs/draft.tex` and `docs/figures/mlpmt_pipeline.pdf` — paper source and pipeline figure.

## Environment

- Python 3.11 or newer
- Dependencies: see `pyproject.toml` and `requirements.txt`
- Tested with scikit-learn 1.9.1 and pandas 3.0.6

Install dependencies with:

```bash
uv sync
# or
pip install -r requirements.txt
```

## Reproducing the reported analyses

The precomputed results are in `artifacts/revision_v7/`. To regenerate them from the included corpus:

```bash
python scripts/revision_analysis.py
```

This script expects `data/pairs.csv`, `data/fault_labels.csv`, and `artifacts/fusion_cache.pkl`. Because the benchmark checkouts are not included, it reuses the precomputed expressibility CSV files rather than re-parsing the original source files.

Run the test suite with:

```bash
python -m pytest -q
```

## Rebuilding the benchmark corpus

The full rebuild requires network access and is substantially longer than the analyses:

```bash
python scripts/setup_benchmark.py --build
```

This provisions BugsInPy, per-project test environments, and the buggy/fixed checkouts, then rebuilds the corpus. The included `data/pairs.csv` and `data/fault_labels.csv` allow the paper's analyses to be reproduced without this step.
